# Data Science & Machine Learning Notes

Welcome to my comprehensive data science repository. This project documents my journey from Python fundamentals to advanced Deep Learning architectures, including theoretical exercises and hands-on projects.

## Repository Structure

The repository is organized into six main modules, following the data science lifecycle:

### [01. Python Basics](./01_Python_Basics)
* **Core Concepts:** Variables, Data Types, and Control Flow.
* **Data Analysis:** Deep dive into **Pandas** and **NumPy**.
* **Visualization:** Creating insightful plots with **Matplotlib**.

### [02. Probability & Statistics](./02_Probability_and_Statistics)
* Statistical Inference & Hypothesis Testing.
* Law of Large Numbers (LLN) & Central Limit Theorem (CLT).
* **Final Home Exam:** Real-world statistical analysis on credit data.

### [03. Statistical Learning](./03_Statistical_Learning)
* **Regression:** Simple, Multiple, and Non-Linear relationships.
* **Model Selection:** Cross-Validation and the Bootstrap.
* **Trees:** Decision Trees, Random Forests, and Boosting (XGBoost).

### [04. Classification](./04_Classification)
* Logistic Regression & Linear Discriminant Analysis (LDA).
* Naive Bayes & KNN Classification.
* Time Series Analysis fundamentals.

### [05. Machine Learning](./05_Machine_Learning)
* **EDA:** Comprehensive Exploratory Data Analysis.
* **Preprocessing:** Data Imputation and Feature Engineering.
* **Unsupervised Learning:** Clustering and Dimensionality Reduction.
* **Applications:** NLP (Natural Language Processing) and Recommendation Systems.

### [06. Deep Learning](./06_Deep_Learning)
* Introduction to Neural Networks.
* Backpropagation and Optimization algorithms.
* Architecture implementation and performance tuning.
